## Мета роботи

Закріпити навички роботи з багатовимірними масивами:

- створення та ініціалізація двовимірних масивів (матриць);
- обхід елементів вкладеними циклами;
- перетворення матриць (арифметичні операції, зсув, видалення рядків і стовпців);
- обертання матриці **in-place**, тобто без додаткового масиву;
- використання тривимірного масиву для моделювання реальних даних (розклад занять).

## Допоміжні методи

| Метод | Опис |
|---|---|
| `generateMatrix(m, n, min, max)` | Генерує матрицю `m × n` випадкових цілих чисел у діапазоні `[min, max]` |
| `printMatrix(matrix, title)` | Виводить матрицю у вигляді таблиці із заголовками `стовпець 1 … стовпець n` та `рядок 1 … рядок m` |
| `cloneMatrix(matrix)` | Створює копію матриці, щоб кожне завдання виконувалось над початковими даними |

## Основні завдання

### 1. Віднімання середнього арифметичного рядка
`subtractRowMean(matrix)`
Від кожного елемента рядка віднімається середнє арифметичне цього рядка. Через це в результаті можуть з'являтися дробові числа.

### 2. Циклічний зсув
`cyclicShift(matrix, k)`
Матриця циклічно зсувається на `k` позицій **вправо** та на `k` позицій **догори**. Індекси обчислюються за модулем, тому працюють будь-які `k`, зокрема від'ємні та більші за розмір матриці:

```js
newI = ((i - k) % m + m) % m;  // догори
newJ = ((j + k) % n + n) % n;  // вправо
```

### 3. Видалення рядків і стовпців з максимальними елементами
`removeMaxRowsAndCols(matrix)`
Знаходиться максимальне значення матриці. Усі рядки та стовпці, у яких воно зустрічається (навіть якщо максимумів кілька), видаляються. Повертається максимум і нова матриця.

### 4. Обертання матриці на 90° за годинниковою стрілкою (in-place)
`rotate90InPlace(matrix)`
Обертання виконується без додаткового масиву: матриця обробляється по «кільцях» від зовнішнього до внутрішнього, а елементи кожної четвірки міняються місцями по колу:

```
верх → право → низ → ліво → верх
```

Складність за пам'яттю `O(1)`. Метод працює лише для **квадратних** матриць: для прямокутної змінюється форма масиву, тому in-place обертання неможливе.

## Додаткове завдання: розклад студентів

Університетська система розкладу для **3 груп** на **5 навчальних днів** по **4 пари** на день.

Дані зберігаються в тривимірному масиві `schedule[3][5][4]` (**Групи × Дні × Пари**). Елемент — назва предмета або `"Вільне вікно"`.

| Метод | Що робить |
|---|---|
| `findBusiestDay(schedule, g)` | Знаходить день (або кілька) з найбільшою кількістю пар для групи `g` |
| `findDaysWithWindows(schedule, g)` | Знаходить дні з «вікнами», тобто вільними парами між двома заняттями. Вільні пари на початку та в кінці дня вікном не вважаються |
| `findStreamLessons(schedule)` | Знаходить **потокові заняття**: один предмет в один час у кількох групах |

## Складність алгоритмів

Нехай матриця має розмір `m × n`, а `N` — розмір сторони квадратної матриці.

| Алгоритм | Час | Додаткова пам'ять |
|---|---|---|
| `generateMatrix` | O(m·n) | O(m·n) |
| `subtractRowMean` | O(m·n) | O(1) |
| `cyclicShift` | O(m·n) | O(m·n) |
| `removeMaxRowsAndCols` | O(m·n) | O(m + n) |
| `rotate90InPlace` | O(N²) | **O(1)** |
| `findBusiestDay` | O(D·P) | O(D) |
| `findDaysWithWindows` | O(D·P) | O(1) |
| `findStreamLessons` | O(D·P·G) | O(G) |

де `G` — кількість груп, `D` — днів, `P` — пар на день.

## Приклад виконання

```
Початкова матриця:
            стовпець 1  стовпець 2  стовпець 3  стовпець 4  стовпець 5
рядок 1     -10         9           -2          -1          -4
рядок 2     1           -8          8           7           3
рядок 3     10          2           -6          -7          1
рядок 4     -10         -9          -9          -9          7

1) Після віднімання середнього арифметичного рядка:
            стовпець 1  стовпець 2  стовпець 3  стовпець 4  стовпець 5
рядок 1     -8.40       10.60       -0.40       0.60        -2.40
...

===== Розклад (додаткове завдання) =====
Група 1: найбільше навантаження — П'ятниця (4 пар)
Група 1: «вікно» у Понеділок, пара(и) №3
Група 1: «вікно» у Вівторок, пара(и) №2
Потокові заняття:
  Понеділок, пара 1: Дискретна математика — Група 1, Група 2, Група 3
  ...
```

Числа в матрицях генеруються випадково, тому при кожному запуску результат відрізняється.
